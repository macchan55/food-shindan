1. 配点設計の原則
各選択肢の加点合計は原則4点。最も強く表れる主軸に3点、補助的に表れる軸に1点を付与する。
一つの回答が複合的な価値観を示す場合は、2点＋2点、または2点＋1点＋1点に分割する。
性別、年齢、学歴、現在の役職、経験年数は診断スコアへ使用しない。
診断結果は各軸の素点を、そのセッションで獲得可能な最大点に対して0〜100へ正規化する。
補助軸はタイプ判定の境界解消、飲食業界適性、適職マッピングに使用し、結果画面では必ずしも全て表示しない。
本配点はVer.2.0の初期仮説。実利用者の「当たっている」評価、タイプ分布、設問別回答率を使いVer.2.1以降で校正する。
2. 軸の定義
コード
軸
定義
HOS
Hospitality（おもてなし）
人を喜ばせ、心地よい時間を届けようとする志向。
CRA
Craft（技術・品質）
技術、味、品質、完成度を高めようとする志向。
TEA
Teamwork（協働）
周囲と協力し、チーム全体で成果を出す志向。
LEA
Leadership（統率）
全体を見て判断し、人や組織を動かす志向。
BUS
Business（事業・数字）
売上、利益、原価、成長、事業性を重視する志向。
CRE
Creativity（創造）
新商品、新体験、新しい方法を生み出す志向。
GRO
Growth（成長）
学習、改善、能力向上を継続する志向。
STA
Stability（安定・再現）
標準化、安定運営、再現性、リスク管理を重視する志向。
CHA
Challenge（挑戦）
未知、変化、独立、新しい可能性へ踏み出す志向。
OWN
Ownership（当事者意識）
担当範囲を越えて結果に責任を持つ志向。
EMP
Empathy（共感）
相手の感情や背景を理解する感受性。
RES
Resilience（耐性）
繁忙、批判、失敗の中でも立て直す力。
DAT
Data Orientation（データ志向）
感覚だけでなく事実、記録、数値から判断する志向。
CUS
Customer Orientation（顧客志向）
顧客のニーズと体験を判断の起点にする志向。

4. スコア計算仕様
各回答の加点を軸ごとに合計し、raw_scoreを算出する。
各軸について、そのユーザーに提示された設問内で獲得可能だった最大点をmax_scoreとする。
normalized_score = round(raw_score / max_score × 100)。
同点や差が小さい場合は、該当軸に対応する補強質問を最大8問提示する。
タイプ判定は単一軸の最高点だけで決めず、64タイプごとに設定した14軸の基準ベクトルとの距離で判定する。
第1候補と第2候補の適合度差が3ポイント未満の場合、結果画面で「隠れタイプ」として第2候補を表示できる。
